
# =====================================================
# PawPrintAI - Complete Setup & Execution Guide
# =====================================================

## PREREQUISITES
- Python 3.10 or higher
- pip (Python package manager)
- macOS/Linux (or Windows with WSL)
- ~5GB disk space (for dependencies + models)

## =====================================================
## STEP 1: INITIAL SETUP
## =====================================================

### 1.1 Clone/Navigate to Project
cd /Users/nyalapallypavankumar/PawPrintAI

### 1.2 Create Virtual Environment
python3 -m venv venv

### 1.3 Activate Virtual Environment
# On macOS/Linux:
source venv/bin/activate

# On Windows (CMD):
venv\Scripts\activate.bat

# On Windows (PowerShell):
venv\Scripts\Activate.ps1

### 1.4 Upgrade pip
pip install --upgrade pip setuptools wheel

### 1.5 Install Dependencies
pip install -r requirements.txt

# This installs:
# - Flask, Flask-CORS, Werkzeug, Gunicorn (Backend)
# - TensorFlow, Keras, NumPy, scikit-learn (ML)
# - OpenCV, Pillow, scikit-image (Image Processing)
# - Pandas, Matplotlib, Seaborn, SciPy (Data Analysis)
# - And more utilities

## =====================================================
## STEP 3: TRAIN THE MODEL
## =====================================================

### 3.1 Configure Training (Optional)
# Edit config.json to customize:
# - image_size, batch_size, epochs
# - learning_rate, label_smoothing
# - augmentation parameters
# - model architecture settings

### 3.2 Run Training Script
python train_model.py

# This will:
# ✅ Validate datasets
# ✅ Set random seeds for reproducibility
# ✅ Build EfficientNetV2-S model
# ✅ Phase 1: Train classifier head (30 epochs)
# ✅ Phase 2: Fine-tune base model (20 epochs)
# ✅ Evaluate on test set
# ✅ Save model, metrics, training history
# ✅ Log all outputs with timestamps

### 3.3 Monitor Training
# View TensorBoard logs (optional):
tensorboard --logdir=backend/model/logs_<TIMESTAMP>

# Outputs saved to backend/model/:
# - footprint_cnn_final.keras (final model)
# - best_model_<TIMESTAMP>.keras (best checkpoint)
# - metrics_<TIMESTAMP>.json (test results)
# - training_history_<TIMESTAMP>.json (training curves)
# - training_metadata_<TIMESTAMP>.json (config + results)
# - class_indices.json (class mappings)

## =====================================================
## STEP 4: RUN THE BACKEND API
## =====================================================

### 4.1 Check API Configuration
# Review backend/app_config.json for:
# - host, port, debug mode
# - file size limits, security settings
# - model paths, logging config

## =====================================================
## TROUBLESHOOTING
## =====================================================

### Issue: "venv not found"
Solution: Recreate virtual environment
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

### Issue: "No module named tensorflow"
Solution: Install missing dependencies
pip install tensorflow keras numpy

### Issue: "Dataset validation failed"
Solution: Check dataset structure
# Ensure dataset/classification/{train,val,test}/*/
# Contains images (jpg, jpeg, png)

### Issue: "Model not loading"
Solution: Check model file exists
ls -lah backend/model/footprint_cnn_final.keras

### Issue: "Port 5000 already in use"
Solution: Use different port in app_config.json
# Or kill process on port 5000:
lsof -ti:5000 | xargs kill -9

### Issue: "Out of memory during training"
Solution: Reduce batch size in config.json
# Change: "batch_size": 32 → "batch_size": 16

### Issue: "Slow inference"
Solution: Use smaller image size in config.json
# Change: "image_size": [224, 224] → [192, 192]
